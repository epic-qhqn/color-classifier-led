3. Giải Mã Hiện Tượng Vật Lý & Thuật Toán

3. Physics & Mathematical Algorithm Explained

A. Nguyên lý biến bóng LED thành mắt cảm biến

A. Physics: Turning an LED into a Sensor

Bóng LED thông thường phát sáng nhờ dòng điện đẩy electron lấp vào các lỗ trống của chất bán dẫn. Tuy nhiên, nếu ta đảo ngược dòng điện bằng kỹ thuật Phân cực ngược (Reverse Bias), LED sẽ ngưng sáng và tạo ra một vùng cản điện (Depletion Region). Lúc này, LED hoạt động hệt như một Tụ điện ký sinh (Parasitic Capacitor) đang ngậm đầy điện.

Normally, an LED emits light when an electrical current forces electrons into the semiconductor's holes. However, if we apply a Reverse Bias voltage, it stops glowing and creates a Depletion Region. The LED now acts precisely like a fully charged Parasitic Capacitor.

Theo Hiệu ứng quang điện (Photoelectric Effect): Khi các hạt ánh sáng (Photon) dội từ vật thể đập ngược vào vỏ LED, năng lượng của chúng sẽ phá vỡ các liên kết nguyên tử trong vùng cản, lập tức giải phóng các hạt electron tự do.

According to the Photoelectric Effect: When reflected light particles (Photons) strike the LED, their energy breaks atomic bonds within the depletion region, instantly freeing electrons.

Lượng electron vừa thoát ra này tạo thành một dòng điện rò rỉ rất nhỏ, âm thầm xả cạn tụ điện ký sinh. Mối liên hệ logic được rút ra là:

Ánh sáng dội lại càng chói ➔ Hạt electron thoát ra càng nhiều ➔ Tụ điện xả điện càng nhanh.

Vi điều khiển chỉ việc đo đếm thời gian xả điện (tính bằng đơn vị micro-giây) là suy ra được mức độ phản xạ ánh sáng.

These freed electrons create a tiny leakage current that silently discharges the parasitic capacitor. The logical relationship is:

Stronger reflected light ➔ More electrons freed ➔ Faster capacitor discharge.

The MCU simply measures this discharge time (in microseconds) to calculate the reflected light intensity.

B. Thuật toán tìm màu sắc (Không gian 3 chiều)

B. Math: Color Matching Algorithm (3D Space)

Khi ta lần lượt chớp 3 tia sáng (Đỏ, Lục, Lam) vào mẫu vật, ta thu về được 3 chỉ số phản xạ tương ứng. Gộp 3 chỉ số này lại, ta có một bộ dữ liệu (R, G, B). Đây được gọi là "Dấu vân tay quang học" của vật thể đó.

By sequentially flashing 3 light pulses (Red, Green, Blue) at the target, we collect 3 reflection values. Combining them yields an (R, G, B) dataset. This is essentially the object's "Optical Fingerprint".

Làm sao để máy tính biết dấu vân tay này thuộc về màu gì? Ta coi bộ 3 số (R, G, B) này tương đương với tọa độ (x, y, z) trong không gian 3 chiều. Ở cấp 2, chúng ta đã học cách tính khoảng cách đường thẳng giữa 2 điểm trong mặt phẳng 2D bằng Định lý Pytago:

d² = (Δx)² + (Δy)²

Máy tính sẽ áp dụng chính xác định lý này nhưng mở rộng lên Không gian 3D (bằng cách cộng thêm trục Z). Ở đây, công thức sẽ đo khoảng cách từ điểm màu ta vừa quét được, tới 14 điểm màu tiêu chuẩn đã nạp sẵn trong bộ nhớ:

How does the MCU recognize this fingerprint? We map the (R, G, B) dataset to (x, y, z) coordinates in a 3D space. As we learned in middle school geometry, the shortest straight-line distance between 2 points on a 2D plane is calculated using the Pythagorean Theorem:

d² = (Δx)² + (Δy)²

The system applies this exact theorem but scales it up to 3D Space (by adding the Z-axis). The formula measures the Euclidean distance from our newly scanned color coordinate to the 14 standard colors pre-loaded in memory:

d = √ (Rđo - Rchuẩn)² + (Gđo - Gchuẩn)² + (Bđo - Bchuẩn)²
d = √ (Rmeasure - Rtarget)² + (Gmeasure - Gtarget)² + (Bmeasure - Btarget)²

Vi điều khiển tính ra 14 khoảng cách d. Khoảng cách nào ngắn nhất (gần bằng 0 nhất) chứng tỏ sai số là thấp nhất ➔ Hệ thống lập tức kết luận đó chính là màu của vật thể!

The MCU calculates 14 d distances. The shortest distance (closest to 0) implies the lowest deviation ➔ The system confidently declares a color match!

* Lưu ý học thuật: Giá trị Trắng (255, 255, 255) trong lý thuyết là giá trị hoàn hảo. Trong thực tế, đây là kết quả sau khi vi điều khiển đã chạy qua hàm map() để hiệu chuẩn (Calibration) quy đổi mức sáng nhất của môi trường về 255.

* Academic Note: The theoretical White value (255, 255, 255) is an ideal state. In practice, this is the result after the MCU runs a map() function to calibrate the brightest ambient level up to 255.

4. Source Code

Để việc đo thời gian xả điện diễn ra chính xác tuyệt đối (tính bằng micro-giây), các lệnh mặc định như digitalRead() của Arduino là quá chậm do phải xử lý qua nhiều lớp phần mềm. Mã nguồn bên dưới ứng dụng kỹ thuật Port Manipulation - ghi đè trực tiếp các bit nhị phân vào thanh ghi (Registers) của lõi vi xử lý để chạy ở tốc độ phần cứng tối đa.

To accurately measure the microsecond discharge time, default commands like digitalRead() are too slow due to multiple software abstraction layers. The source code below utilizes Port Manipulation - writing binary bits directly to the CPU's Registers to achieve raw hardware execution speed.

// CHÂN CẮM: LED Thu (Cảm biến): Anode -> D2, Cathode -> D3.// WIRING: Sensor LED: Anode -> D2, Cathode -> D3.
#define DETECT_ANODE_BIT   2 // Bit 2 trên PORTD (D2)// Bit 2 on PORTD (D2)
#define DETECT_CATHODE_BIT 3 // Bit 3 trên PORTD (D3)// Bit 3 on PORTD (D3)

unsigned int readLightSensorFast() {
  // 1. Phân cực ngược để nạp đầy "tụ ký sinh"// 1. Reverse Bias to charge the "parasitic capacitor"
  DDRD |= (1 << DETECT_ANODE_BIT) | (1 << DETECT_CATHODE_BIT); 
  PORTD &= ~(1 << DETECT_ANODE_BIT); // D2 = LOW// D2 = LOW
  PORTD |= (1 << DETECT_CATHODE_BIT); // D3 = HIGH// D3 = HIGH
  
  delayMicroseconds(100); // Đợi sạc đầy// Wait for full charge

  // 2. Chuyển Cathode thành INPUT và tắt pull-up nội bộ// 2. Switch Cathode to INPUT and disable internal pull-up
  DDRD &= ~(1 << DETECT_CATHODE_BIT);  
  PORTD &= ~(1 << DETECT_CATHODE_BIT); 

  // 3. Đếm thời gian xả (Vòng lặp siêu tốc)// 3. Count discharge time (Super fast loop)
  unsigned int count = 0;
  unsigned int timeout = 60000; // Tránh lặp vô hạn trong phòng tối đen// Prevent infinite loop in pitch black
  
  // Đọc trạng thái vật lý trực tiếp từ thanh ghi PIND// Read physical state directly from PIND register
  while ((PIND & (1 << DETECT_CATHODE_BIT)) && (count < timeout)) {
    count++;
  }
  
  return count; // Thời gian xả ngắn = Ánh sáng phản xạ mạnh// Lower count = Faster discharge = Brighter light
}
// CHÂN CẮM: LED Thu (Cảm biến): Anode -> IO18, Cathode -> IO19.// WIRING: Sensor LED: Anode -> IO18, Cathode -> IO19.
#include "driver/gpio.h"
#define PIN_ANODE   18
#define PIN_CATHODE 19

unsigned int readLightSensorESP32() {
  gpio_set_direction((gpio_num_t)PIN_ANODE, GPIO_MODE_OUTPUT);
  gpio_set_direction((gpio_num_t)PIN_CATHODE, GPIO_MODE_OUTPUT);

  // Ép chân tín hiệu qua thanh ghi REG_WRITE siêu tốc// Force pin states via high-speed REG_WRITE
  REG_WRITE(GPIO_OUT_W1TC_REG, (1 << PIN_ANODE));   // Clear -> LOW// Clear -> LOW
  REG_WRITE(GPIO_OUT_W1TS_REG, (1 << PIN_CATHODE)); // Set -> HIGH// Set -> HIGH
  
  delayMicroseconds(50); 

  // Ngắt nguồn, cho phép Photon xả điện// Cut power, allow Photons to discharge
  gpio_set_direction((gpio_num_t)PIN_CATHODE, GPIO_MODE_INPUT);
  gpio_set_pull_mode((gpio_num_t)PIN_CATHODE, GPIO_FLOATING);

  unsigned int count = 0;
  unsigned int timeout = 200000; // Xung nhịp ESP32 cao, cần timeout lớn// High clock speed requires higher timeout

  // Đọc từ thanh ghi đầu vào GPIO_IN_REG// Read from input register
  while ((REG_READ(GPIO_IN_REG) & (1 << PIN_CATHODE)) && (count < timeout)) {
    count++;
  }
  
  return count;
}
